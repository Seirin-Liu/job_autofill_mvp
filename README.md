# 秋招自动填报助手

<img width="391.5" height="492" alt="image" src="https://github.com/user-attachments/assets/6a8410f7-fd11-4c2a-9eb1-fc38cce38122" />

本项目用于辅助填写秋招 / 校招网申信息。个人数据保存在本地，支持 Web 页面维护个人档案、浏览器插件快捷填入、常见字段自动识别，以及实习、项目、获奖、家庭成员等重复信息的辅助填写。

当前版本采用纯本地规则匹配，不依赖外部 AI API，也不会自动点击招聘网站最终“提交”按钮。

## 主要功能

- 本地保存个人简历信息
- Web 页面直接编辑完整个人资料
- 缺少已支持字段时自动补齐 JSON Schema
- 浏览器插件快捷填入本地数据
- 快捷填入面板支持拖动，避免遮挡网页
- 快捷填入支持分类 Tab 和搜索
- 填写成功后自动跳到下一个输入框
- 文本输入框支持追加填写，非文本控件直接覆盖 / 重新选择
- 自动识别常见招聘表单字段
- 支持硕士、本科、高中等多段教育经历匹配
- 支持实习、项目、获奖、家庭成员等重复经历逐条添加
- 插件可直接打开浏览器中的完整个人信息编辑页面
- 不自动提交最终申请，保留人工检查和确认

## 首次运行

1. 双击：

```text
install.bat
```

首次安装会自动创建：

```text
data/
data/assets/
```

并生成当前版本支持的完整 `profile_seed.json` 结构。

2. 启动本地服务：

```text
start.bat
```

3. 浏览器打开：

```text
http://127.0.0.1:8765/
```

或：

```text
http://127.0.0.1:8765/profile
```

可直接编辑并保存完整个人简历信息。

## 安装浏览器插件

Chrome 打开：

```text
chrome://extensions/
```

Edge 打开：

```text
edge://extensions/
```

开启“开发者模式”，选择“加载已解压的扩展程序”，加载项目中的：

```text
extension/
```

更新插件代码后，需要在扩展管理页点击一次“重新加载”，并刷新正在填写的招聘网页。

## 使用方式

### 本地数据快捷填入

推荐日常使用：

```text
本地数据快捷填入
```

使用流程：

```text
点击招聘网站中的目标输入框
↓
打开插件
↓
点击“本地数据快捷填入”
↓
按分类 Tab / 搜索快速找到本地数据
↓
点击对应内容完成填写
↓
自动跳到下一个输入框
```

快捷填入面板可以拖动位置，避免遮挡招聘网站按钮。

填写规则：

- 普通文本框 / textarea：在现有文字末尾追加
- 下拉框 / 单选框 / 复选框：直接重新选择
- 日期 / 数字 / 时间等非文本输入：直接覆盖
- 自定义下拉框：优先按选项匹配后重新选择

### 扫描并自动填写全部

也可以使用：

```text
扫描并自动填写全部
```

系统会根据本地规则和已保存的字段映射，自动处理普通字段。

对于实习、项目、获奖、家庭成员等重复信息，会按照：

```text
新增
↓
填写
↓
校验
↓
确认
↓
检查结果
```

的方式逐条处理。出现失败时会停止当前重复信息流程，避免继续错填。

## 个人信息编辑

插件中提供：

```text
在浏览器中编辑完整个人信息 ↗
```

点击后会打开：

```text
http://127.0.0.1:8765/profile
```

可以维护：

- 基本信息
- 教育经历
- 实习经历
- 项目 / 科研经历
- 校园经历
- 学生活动
- 技能水平
- 获奖经历
- 家庭关系
- 自我评价
- 职业规划
- 求职偏好

新增到系统默认 Schema 的字段，会自动补充到旧 JSON 中，不覆盖已有值。

## 数据存储

个人数据主要保存在：

```text
data/profile_seed.json
data/autofill.db
data/assets/
```

其中：

- `profile_seed.json`：主要个人档案
- `autofill.db`：本地历史字段映射等数据
- `assets/`：证件照、生活照等本地文件

建议不要将真实个人数据提交到 GitHub。

`.gitignore` 建议包含：

```gitignore
.env
.venv/
__pycache__/
.pytest_cache/
*.pyc
data/
```

如果 `data/` 之前已经被 Git 跟踪，仅添加 `.gitignore` 不会停止跟踪，需要执行：

```bash
git rm -r --cached data
git commit -m "stop tracking local personal data"
```

## 更新程序

重新拉取或覆盖代码后：

1. 关闭原有后端进程
2. 重新启动：

```text
start.bat
```

3. 打开浏览器扩展管理页面
4. 点击插件“重新加载”
5. 刷新招聘网站页面

如果更新了后端依赖，可执行：

```text
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```
