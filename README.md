# 秋招自动填报助手

一个用于秋招网申表单辅助填写的本地化工具，支持：

- 本地保存个人信息
- 浏览器插件快捷填入
- 扫描并自动填写常见表单字段
- 实习、获奖、家庭成员等重复信息逐条添加
- 可选接入 DeepSeek API 做字段语义识别
- 不自动提交最终申请，保留人工确认

---

## 一、项目结构

```text
job-autofill-mvp/
├─ backend/          # FastAPI 后端
├─ extension/        # Chrome / Edge 浏览器插件
├─ data/             # 本地个人信息与 SQLite 数据库
├─ .env              # DeepSeek 配置
├─ install.bat       # 首次安装
├─ start.bat         # 启动后端
└─ README.md
```

---

## 二、首次运行

### 1. 解压项目

将项目解压到本地目录，例如：

```text
E:\job-autofill-mvp
```

建议路径中不要包含特殊字符。

### 2. 安装依赖

首次使用时双击：

```text
install.bat
```

等待 Python 虚拟环境和依赖安装完成。

### 3. 配置 DeepSeek（可选）

编辑项目根目录：

```text
.env
```

填写：

```env
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
```

如果不配置 DeepSeek，本地规则和快捷填入功能仍然可以使用。

### 4. 启动后端

双击：

```text
start.bat
```

正常启动后会看到：

```text
Starting Job Autofill backend at http://127.0.0.1:8765
```

浏览器可访问：

```text
http://127.0.0.1:8765
```

---

## 三、安装浏览器插件

Chrome 打开：

```text
chrome://extensions/
```

Edge 打开：

```text
edge://extensions/
```

然后：

1. 开启“开发者模式”
2. 点击“加载已解压的扩展程序”
3. 选择项目中的：

```text
extension
```

以后如果更新了插件代码，需要在扩展管理页点击一次“重新加载”，并刷新招聘网站。

---

## 四、录入个人信息

打开浏览器插件，进入：

```text
个人档案
```

填写并保存自己的信息，包括：

- 基本信息
- 教育经历
- 实习经历
- 校园经历
- 获奖经历
- 家庭成员
- 技能信息
- 求职偏好

所有数据默认保存在本地 `data` 目录中。

## 五、使用方式

### 方式一：本地数据快捷填入

推荐优先使用。

操作流程：

1. 打开招聘网站
2. 点击插件中的“本地数据快捷填入”
3. 网页右侧会显示本地档案
4. 先点击招聘网站中需要填写的输入框
5. 再点击右侧对应的数据
6. 数据会自动写入当前字段

这种方式不需要扫描网页，也不需要 AI 识别，适合稳定、可控地填写。

---

### 方式二：扫描并自动填写全部

点击：

```text
扫描并自动填写全部
```

系统会尝试自动完成：

- 姓名、手机号、邮箱等普通字段
- 教育信息
- 校园经历
- 实习经历逐条添加
- 获奖经历逐条添加
- 家庭成员逐条添加

如果某条重复信息提交失败，程序会停止后续自动操作，避免连续误填。

---

## 六、更换使用人

如果需要给其他人使用，建议使用空数据包。

操作步骤：

1. 关闭 `start.bat`
2. 删除当前项目中的：

```text
data
```

3. 将空数据包里的 `data` 文件夹复制进项目
4. 重新运行：

```text
start.bat
```

5. 新用户打开插件，在“个人档案”中填写自己的信息

注意：不要直接保留上一位用户的 `autofill.db`，其中可能包含个人资料和历史字段映射。

## 七、常见问题

### 1. start.bat 启动失败

先确认是否执行过：

```text
install.bat
```

如果 `.venv` 不存在，请重新运行安装脚本。

### 2. .env 出现编码错误

建议将 `.env` 保存为：

```text
UTF-8
```

如果 DeepSeek 配置有问题，可以暂时清空 API Key，本地填报功能仍可使用。

### 3. 插件更新后没有生效

进入：

```text
edge://extensions/
```

或：

```text
chrome://extensions/
```

对插件点击：

```text
重新加载
```

然后刷新招聘网站页面。

### 4. 某些下拉框或日期无法自动填写

部分招聘网站使用 Ant Design、Element Plus、React 自定义组件，普通 HTML 填值方式可能无法生效。

此时优先使用：

```text
本地数据快捷填入
```

如果仍然无法填写，需要针对该网站的组件做专门适配。

---

## 八、安全说明

- 个人信息默认保存在本地
- DeepSeek 主要用于识别网页字段含义
- 普通字段识别时尽量不上传真实个人数据
- 工具不会自动点击最终“提交申请”
- 提交前请人工检查所有信息
